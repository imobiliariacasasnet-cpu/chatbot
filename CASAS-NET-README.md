# Casas Net Imóveis — site prototype

This branch adds a premium landing-page prototype to the existing Next.js app.

## Previewing the interface
The landing page is currently served from the app's root route. The layout is responsive and uses a black, cream, and metallic-gold visual system.

## Important before public launch
- Replace the typographic mark in the header with the official Casas Net logo asset.
- Replace illustrative home cards and photography with authorized real inventory.
- Connect the inventory/search to Jetimob or another verified source of truth.
- Connect lead forms to a secured backend/CRM and configure appropriate consent, privacy notice, retention, and access controls.
- Add official phone, WhatsApp, email, and business address after verification.
- Implement the individual property pages, favorites persistence, comparison, appointment booking, and admin controls before advertising these capabilities as live.
- Configure and verify SEO, analytics/consent, sitemap, robots, accessibility and production performance.
- This branch is a prototype; no public production deployment is implied by the commits.

## Visual direction
Original editorial design influenced by premium product-site principles: cinematic architecture photography, ample whitespace, strong type hierarchy, responsive layout, subtle transitions, and restrained black/white/gold identity. It is not a copy of Apple’s website.
